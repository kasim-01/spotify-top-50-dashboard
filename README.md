# Spotify Top 50 Dashboard (Power BI)

An interactive Power BI dashboard exploring the Spotify Top 50 (World) dataset — song popularity, artists, album types, and release trends.

## Features
- KPI cards: total distinct songs, average popularity, average track duration
- Songs/popularity breakdown by artist
- Album type distribution (donut chart)
- Explicit vs. non-explicit song split
- Popularity trend over time (by quarter/year)
- Interactive slicers to filter by song

## Tools
Power BI Desktop, DAX (custom measures for popularity, duration, explicit content)
